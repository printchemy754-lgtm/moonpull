# Moonpull

**Ты не управляешь лодкой. Ты управляешь морем.**

3D-хайпер-кэжуал на Godot 4.6, вертикальный экран. Лодка плывёт по каньону сама. Держишь палец — Луна поднимается и тянет прилив вверх, отпускаешь — вода уходит.

### Что есть в игре
- **5 миров** по 4 уровня (дальше по кругу): Sunset Canyon, Moonlit Bay, Jungle Gorge, Frost Fjord, Ember Isles. У каждого мира своё небо, вода, скалы, декорации, водопады или лавопады и частицы (светлячки, снег, искры).
- **Препятствия:** риф (подними воду), мост (опусти), ворота (попади в окно), **разводной мост** (двигается вверх-вниз), **дышащий риф** (поднимается и опускается).
- **Кольца и бонусы:** кольцо скорости (быстрее, жемчуг x2), лунное кольцо (замедление), щит (переживает одно крушение), магнит (притягивает жемчуг).
- **Скорость:** базовая растёт с каждым уровнем (7 → 12.5), кольца дают ускорение или замедление.
- **Монеты и звёзды:** золотые монеты (каждая = 10) выложены цепочками и подсказывают правильный путь. 1–3 звезды за уровень по доле собранных монет. За пролёт впритык даётся +20.
- **Стиль «inked cartoon»:** toon-освещение (чёткие цветовые зоны) и тёмные контуры у лодки, препятствий, монет и луны, в одном стиле с логотипом. Кнопки и панели тоже с чернильной обводкой.
- **Капитан** на борту каждой лодки: когда держишь палец, он поднимает руки и «тянет Луну».
- **Мастерская** (кнопка BOAT в меню): корпус (6 форм: Dinghy, Tugboat, Speedster, Lantern Junk, Rubber Duck, Moon Skiff), краска (10 цветов), паруса (10), флаг (7 узоров), шляпа капитана (6), след на воде (6). Всё за монеты, примерка сразу видна в 3D.
- **Меню** с картой мира, магазин с 3D-витриной, настройки (звук, музыка, вибрация), пауза, обучение на первых уровнях, знакомство с каждой новой механикой.
- **Логотип и шрифты:** логотип и иконка в `game/logo.svg`, `game/icon.svg`; шрифты Fredoka и Lilita One (лицензия OFL, можно в коммерческой игре).
- Музыка и все звуки генерируются кодом.

### Чтобы не надоедало (v9)
- **FEVER:** каждое чисто пройденное препятствие заряжает шкалу (впритык идёт за два). При полной шкале включается FEVER: лодка таранит препятствия насквозь (SMASH +30), монеты идут x2, работает магнит, скорость выше.
- **Новое каждые несколько уровней:** с 7-го появляются **движущиеся ворота**, с 10-го — **плазменные мины** (проходишь над ними или под ними, на выбор), с 13-го — **гейзер** (подбрасывает воду), с 16-го — **воронка** (утягивает воду вниз).
- **Босс в конце каждого мира** (уровни 4, 8, 12…): неоновый корабль-матка летит впереди. Каждое пройденное препятствие бьёт его лазером, у него есть полоска HP, в финале он взрывается и даёт бонус от 1000 монет.
- **COIN RUSH** (уровни 6, 10, 14…): бонусный уровень, где монеты разбросаны очень плотно, а FEVER почти заряжен с самого старта.
- **POWER (прокачка навсегда):** 5 улучшений по 5 уровней — время FEVER, заряд FEVER, цена монеты (10 → 20), магнит, щит на старте. Всё вместе стоит около 160 000 монет.
- Новые задания: «Включи FEVER N раз», «Разбей N препятствий».
- Проверка проходимости: `tools/sim.gd` гоняет бота с человеческой реакцией через настоящий генератор уровней.

### Музыка
- Синтвейв-саундтрек, сгенерирован кодом (`tools/make_music.py`), поэтому он полностью наш и его можно использовать в коммерческой игре: спокойный трек в меню, драйвовый в заезде, в FEVER музыка ускоряется.
- Свои треки для Хэллоуина (орган, колокольчики) и Рождества («Jingle Bells» — общественное достояние, 1857 г.).

### Трамплины (с 3-го уровня)
- Лодка влетает на трамплин, взлетает над стеной и делает трюк (FLIP / BARREL ROLL / SPIN, +50), а монеты по дуге в воздухе собираются сами.

### Хэллоуин и Рождество
- **HALLOWEEN EVENT** (10 окт – 10 нояб) и **CHRISTMAS EVENT** (1 дек – 10 янв) включаются сами по дате. В настройках есть кнопка SEASON: AUTO / OFF / HALLOWEEN / CHRISTMAS.
- Праздничный вид всех миров: тыквы, гирлянды, летучие мыши / ёлки, снег, огоньки. Монеты становятся тыковками или подарками.
- Праздничные предметы для лодки: за каждый пройденный уровень в праздник даётся один из них (шляпа ведьмы, краска PUMPKIN, след GHOST / шапка Санты, краска CANDY CANE, след SNOWFALL).

### Лёгкий старт (для новичков и детей)
- **3 жизни на уровень:** после крушения лодка сама появляется перед препятствием, реклама не нужна. Сердечки видны слева сверху.
- **HELPER MODE:** если уровень проигран 2 раза подряд, следующая попытка медленнее и со щитом.
- **Мягкое начало:** первые уровни медленнее, проёмы шире, рифы ниже, а задевать край можно сильнее.
- **Подсказки HOLD! / LET GO!** до 6-го уровня, а в HELPER MODE всегда.
- **Рекорд даже при проигрыше:** «NEW RECORD: 74%!».
- Проверка: `tools/sim_kid.gd` гоняет «неаккуратного» бота: на первых уровнях он почти не разбивается.

### CrazyGames (браузер)
- В веб-версию встроен **CrazyGames SDK v3**: их реклама (rewarded и midgame), сохранение прогресса через **Data Module**, сигналы gameplayStart/Stop, happytime, выключение звука из настроек CrazyGames.
- В браузере скрыты гонка по Wi-Fi и кнопка «Поделиться» (на порталах нельзя ссылки на магазины приложений).
- Готовая папка для загрузки: Actions → последняя сборка → артефакт **moonpull-web-crazygames-N**. Распакуй и перетащи папку (там `index.html`) в форму CrazyGames.
- В форме: Engine **godot**, Save progress **Yes, using the Data Module**, галочки **mobile** и **muting audio through SDK**, multiplayer **нет**.
- На GitHub Pages SDK не активен, там реклама просто симулируется.

### iPhone (IPA)
Задача **ios** в Actions собирает игру на Mac-серверах GitHub → артефакт **moonpull-ios-N** с файлом `moonpull-unsigned.ipa`.
- Это **неподписанная** IPA: на iPhone её ставят через Sideloadly / AltStore с бесплатным Apple ID (подпись живёт 7 дней).
- Для TestFlight и App Store нужен аккаунт Apple Developer ($99/год) — тогда в сборку добавляется подпись.
- На iPhone пока нет рекламы и Firebase (рекламный модуль написан для Android): реклама в iOS-сборке симулируется.

### Аналитика (Firebase)
Проект Firebase **moonpull-d6076**, пакет игры **com.streamlet.moonpull**. Firebase сам считает установки, удержание D1/D7, длину сессий. Игра дополнительно шлёт события: `level_start`, `level_end` (успех/провал, на каком препятствии), `tutorial_complete`, `endless_start/endless_end`, `race_end`, `ad_rewarded` (где смотрят рекламу), `ad_interstitial`, `spend_virtual_currency` (что покупают), `chest_open`, `level_up` (ранг), `daily_gift`, `share`.
Данные появляются в Firebase → Analytics → Dashboard через ~24 ч (в реальном времени — раздел Realtime / DebugView).
Конфиг: `android-plugin/google-services.json` → значения в `android-plugin/godotads/src/main/res/values/google_services.xml`. Если пересоздашь Firebase-приложение, пришли новый json.

### Что взято у Crossy Road
- **ENDLESS** — бесконечная река с рекордом: сложность и скорость растут с расстоянием, обычный игрок держится 1–3 минуты, сильный — 10+. Рекорд в меню, «NEW BEST!», мгновенный рестарт, задание «Score X in Endless».
- **SHARE** — кнопка «Поделиться» после заезда (Android share sheet; в браузере копирует текст со ссылкой на Google Play).
- **MYSTERY BOX** (1 500 монет) — гарантированно новый предмет, иногда редкий: аналог машины с призами.
- **Мягкая реклама:** interstitial только с 6-го уровня, не чаще раза в 4 рестарта и 75 секунд. Основной доход — добровольная rewarded-реклама.

### Долгий прогресс (чтобы возвращались)
- **Ранг капитана (1 → 50+):** опыт за монеты, уровни, звёзды, гонки, задания и сундуки. За каждый ранг даются монеты, за каждый 5-й — сундук, а на рангах 10/15/20/30/40/50 открываются **эксклюзивы**, которые нельзя купить: шляпа PIRATE, флаг CHAMPION, краска GOLDEN, паруса GALAXY, стены GOLDEN TEMPLE и NEON CITY. Темп: 10-й ранг ≈ 1 ч, 20-й ≈ 4 ч, 50-й ≈ 20+ ч.
- **7-дневная серия:** награда растёт каждый день, на 7-й день — эксклюзивный след FIRE. В окне подарка видно, что будет завтра.
- **Коллекция:** 60 предметов, редкость COMMON / RARE / EPIC / LEGENDARY / EXCLUSIVE, всё вместе стоит около 170 000 монет (≈ 14 ч игры).
- **Стены (WALLS):** 8 стилей — Canyon, Harbor, Wooden Pier, Village, Crystal Cave, Candy Land, Golden Temple, Neon City. Левый и правый берег настраиваются отдельно.

### Меню в стиле Going Balls
- **Профиль:** имя капитана (кнопка слева вверху), кубик — случайное имя. Имя видно над лодкой в гонках.
- **RACE:** гонка против 3 ИИ-капитанов (работает везде) или **Wi-Fi гонка** до 4 игроков в одной сети (Android). Создатель комнаты видит код вида `1.37`, остальные вводят его. Награды: 600 / 300 / 150 / 60 монет, x2 за рекламу. При крушении в гонке — респавн без рекламы.
- **TASKS:** 3 ежедневных задания (собрать монеты, пройти уровни, близкие пролёты, кольца, 3 звезды, гонки) + бонус 500 за все три.
- **CHEST:** бесплатный сундук каждые 4 часа и звёздный сундук за каждые 10 звёзд: монеты или новые предметы для лодки.
- Онлайн-гонка с незнакомыми игроками через интернет требует своего сервера — можно добавить позже.

### Монетизация (AdMob)
- **Рулетка-множитель** на экранах победы и крушения: стрелка бегает по x2 x3 x5 x3 x2, игрок жмёт CLAIM, смотрит рекламу и получает монеты × множитель. «No thanks» появляется через 1.4 с.
- **CONTINUE** после крушения (реклама) — продолжить с места крушения, 1 раз за попытку.
- **Бесплатные монеты** +500 за рекламу (в меню и магазине), раз в 2 минуты.
- **Ежедневный подарок**: 100 × день серии (до 700), x2 за рекламу.
- **Баннер** внизу и **interstitial** не чаще раза в 3 раунда, с 3-го уровня.
- Кнопка **PRIVACY** в настройках (изменить согласие GDPR) — появляется у игроков из ЕС.
- Монеты, собранные до крушения, не сгорают.

### Материалы для Google Play (`store/`)
`icon-512.png` (иконка 512×512), `feature-graphic-1024x500.png` (баннер страницы), `logo.png`. Пересоздать: `python3 tools/make_logo.py`.

Проходимость уровней проверяется симуляцией (`tools/sim.py`, 30 уровней × 4 варианта), а при каждой сборке бот на GitHub проходит 14 уровней (job **test**).

## Реклама (AdMob)

| Формат | Где показывается |
|---|---|
| Баннер | внизу экрана, постоянно |
| Rewarded | «CONTINUE» после крушения (1 раз за попытку) и «x3 PEARLS» после победы |
| Interstitial | не чаще 1 раза в 3 раунда, не раньше 3-го уровня и не чаще раза в 45 с |

Есть согласие GDPR через Google UMP: в ЕС без него AdMob не будет показывать рекламу.

Твои ID из AdMob уже вписаны (приложение «MoonPull»: баннер, interstitial, rewarded). Пока в `game/scripts/ads.gd` стоит `USE_TEST_ADS := true`, игра показывает **тестовую** рекламу Google. Так безопасно играть самому: клики по своей настоящей рекламе могут привести к блокировке аккаунта AdMob.

**Перед публикацией в Google Play:**
1. В `game/scripts/ads.gd` замени `USE_TEST_ADS := true` на `false`.
2. В AdMob → Privacy & messaging создай сообщение GDPR, иначе в ЕС реклама не покажется.
3. После публикации привяжи приложение в AdMob к странице в Google Play и добавь файл app-ads.txt (AdMob сам подскажет).

## Всё через браузер — ничего не устанавливаем

Нужен только аккаунт GitHub. Сборка идёт на серверах GitHub. Код можно править и запускать команды в **Codespaces** — это VS Code с терминалом прямо в браузере (бесплатно до 120 часов в месяц).

### 1. Создать репозиторий и залить проект
1. На github.com: **New repository** → имя `moonpull` → **Private** → поставь галочку *Add a README file* → **Create**.
2. В репозитории: зелёная кнопка **Code** → вкладка **Codespaces** → **Create codespace on main**. Откроется редактор в браузере.
3. Перетащи `moonpull.zip` в панель файлов слева, затем в терминале снизу выполни:
   ```bash
   unzip -o moonpull.zip && cp -r moonpull/. . && rm -rf moonpull moonpull.zip
   git add -A && git commit -m "Moonpull" && git push
   ```
   Codespaces заливает и скрытую папку `.github` со сборкой. Обычная загрузка файлов через сайт её иногда теряет, поэтому лучше так.

### 2. Включить браузерную версию (один раз)
**Settings → Pages → Source: GitHub Actions.**

### 3. Получить APK, AAB и ссылку на игру
Вкладка **Actions** → прогон «Build (APK + AAB + Web)». Сборка запускается при каждом `git push`, а также вручную кнопкой *Run workflow*.
- **Artifacts** внизу страницы прогона: `moonpull-android-N.zip`, внутри `moonpull.apk` и `moonpull.aab`.
- **deploy-web** показывает ссылку вида `https://<ник>.github.io/moonpull/`. Это игра в браузере: открой её на телефоне и тестируй. Реклама там симулируется.

APK можно скачать прямо на Android-телефон (зайди на GitHub через браузер телефона), распаковать и установить.

> С приватным репозиторием GitHub Pages доступен только на платном плане. На бесплатном аккаунте для браузерной версии сделай репозиторий публичным (*Settings → General → Danger Zone → Change visibility*) или просто пропусти шаг 2: APK и AAB собираются в любом случае.

### 4. Ключ подписи для Google Play (один раз, в Codespaces)
Без ключа CI подписывает сборку **одноразовым** ключом. Для тестов APK это нормально, но для Google Play не годится.
```bash
bash tools/make_keystore.sh
```
1. Открой `upload.keystore.b64` в редакторе и скопируй весь текст.
2. Добавь в *Settings → Secrets and variables → Actions → New repository secret*:
   - `KEYSTORE_BASE64` — скопированный текст;
   - `KEYSTORE_PASSWORD` — пароль, который ты ввёл;
   - `KEY_ALIAS` — `upload`.
3. Правой кнопкой по `upload.keystore` → **Download** и сохрани в надёжное место (например, в облако). В git он не попадёт, он в `.gitignore`.
4. Удали оба файла из Codespace.

`versionCode` увеличивается сам, он равен номеру прогона CI.

### Правки кода
- **Codespaces**: правишь файлы → в терминале `git add -A && git commit -m "..." && git push` → через ~10 минут новая сборка.
- **Мелочи** (например, ID рекламы в `game/scripts/ads.gd`): открой файл на github.com → значок карандаша → **Commit changes**. Сборка запустится сама.

## Структура

```
game/                       проект Godot
  scripts/main.gd           правила, камера, ход игры, автотест
  scripts/level_gen.gd      генератор уровней и правила прилива
  scripts/world.gd          мир: вода, каньон, препятствия, эффекты
  scripts/boat.gd           модульная лодка + капитан + эффекты
  scripts/custom.gd         каталог мастерской (цены, редкость, эксклюзивы)
  scripts/ranks.gd          ранги капитана и награды
  scripts/walls.gd          8 стилей берегов (детали склеиваются в один меш)
  scripts/toon.gd           мультяшные материалы + контуры
  shaders/toon, outline     шейдеры стиля
  scripts/themes.gd         5 миров
  scripts/ui.gd, icons.gd   интерфейс и векторные иконки
  scripts/mult_bar.gd       рулетка-множитель
  scripts/missions.gd       ежедневные задания
  scripts/rival.gd          соперник в гонке (ИИ или игрок по Wi-Fi)
  scripts/net.gd            Wi-Fi гонка (комнаты по коду)
  fonts/                    Fredoka, Lilita One (OFL)
  scripts/ads.gd            реклама (на ПК симулируется)
  scripts/save.gd, sfx.gd   сохранения, звуки и музыка
tools/sim.py                проверка проходимости уровней
tools/make_logo.py          логотип, иконка, графика для стора
store/                      готовые картинки для Google Play
  addons/godot_ads/         подключает рекламный плагин при экспорте
android-plugin/             Java-плагин AdMob (CI собирает его в .aar)
.github/workflows/          сборка APK + AAB + веб-версия
```
